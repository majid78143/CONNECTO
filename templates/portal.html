📚 Quick Start

Use your bot token to send messages and interact with CONNECTO servers.

# Example: Send a message via bot token
curl -X POST https://connecto.app/api/bot/message \
  -H "Authorization: Bot YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"channel_id":"abc123","content":"Hello from my bot!"}'
